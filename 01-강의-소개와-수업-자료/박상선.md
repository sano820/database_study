## 예제 / 실습 메모
01) 데이터베이스 설계가 소프트웨어 개발에서 가장 중요한 요소로 간주되는 주된 이유는 무엇일까요?
1. 디버깅 시간을 단축해서
2. 초기 개발 비용을 절감해서
3. 개발 언어 선택에 영향을 주어서
4. 애플리케이션 코드의 기반이 되어서


02) 현대 소프트웨어 개발 환경에서 데이터베이스 설계자가 직면하는 주요 난제 중 하나는 무엇일까요?
1. 새로운 데이터베이스 기술 학습 부담
2. 전통적 이론과 실무 적용의 괼
3. 분산 시스템 환경 구축의 어려움
4. 데이터 보안 요구사항의 복잡성

03) 데이터베이스 설계 과정에서 일반적으로 따르는 세가지 주요 모델링 단계는 무엇일까요?
1. 개념 논리 물리
2. 요구사항 기능 성능
3. 분석 구현 테스트
4. 시스템 서비스 사용자

04) MySQL Server와 MySQL Workbench의 주된 역할 차이는 무엇일까요?
1. 서버는 데이터 저장, 워크벤치는 데이터 분석
2. 서버는 데이터 백업, 워크벤치는 복구 도구
3. 서버는 데이터베이스 자체, 워벤치는 클라이언트 도구
4. 서버는 데이터 처리, 워크벤치는 보고서 생성

05) MySQL WorkBench 연결이 실패할 때 가장 먼저 확인해야할 사항은 무엇일까요?
1. MySQL Server 실행 상태
2. 방화벽 설정
3. Workbench 재설치
4. 운영체제 업데이트
