## 핵심 요약
요구 사항 정의(내 예시) => 명사와 동사에 따라 정의 ( 명사 = 엔티티 / 동사 = 관계 )
    - 사용자 기능
    - 게시글 기능
    - 파일 기능

엔티티를 분류하는 주요 기준은 존재 형태, 생성 시점 및 역할, 존재 종속성.
- 유형 엔티티
    - 사원, 학생
    - 상품, 자재
    - 강의실, 창고
- 개념 엔티티
    - 부서 조직
    - 계좌, 보험 상품
    - 과목, 학과
- 사건 엔티티
    - 주문, 계약
    - 결제, 임금
    - 수강신청, 예약
