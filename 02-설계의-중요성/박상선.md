## 핵심 요약
설계 3단계 
    - 개념적 설계 = 데이터는 무엇이며, 어떤 관계를 가지는가. => ERD
    - 논리적 설계 = 어떤 규칙을 적용해야 하는가? => 정규화
    - 물리적 설계 = 테이블 스키마 최적화 => SQL 스크립트(create table ....)

엔티티 = 릴레이션 - 테이블
세부 항목 = 속성 = 열, 컬럼
데이터단위 = 인스턴스 = 행(튜플)
