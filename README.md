# 데이터베이스 설계 스터디

김영한의 [실전 데이터베이스 - 설계 1편, 현대적 데이터 모델링 완전 정복](https://www.inflearn.com/course/%EA%B9%80%EC%98%81%ED%95%9C-%EC%8B%A4%EC%A0%84-%EB%8D%B0%EC%9D%B4%ED%84%B0%EB%B2%A0%EC%9D%B4%EC%8A%A4-%EC%84%A4%EA%B3%841%ED%8E%B8) 강의를 듣고 정리하는 스터디입니다.

## 참여자

- 한선우
- 박상선

## 진행 방식

- 강의는 총 13개 섹션(83개 강의, 16시간 11분)으로 구성되어 있습니다.
- 섹션(챕터) 단위로 폴더가 나뉘어 있고, 각자 자신의 이름으로 된 md 파일에 정리 내용을 올립니다.
- 파일 상단에 강의 목록 체크리스트가 미리 채워져 있으니, 들은 강의를 체크하면서 아래 항목을 채웁니다.
  - **핵심 요약**: 강의 내용 정리
  - **예제 / 실습 메모**: 실습 코드, ERD, 쿼리 등
  - **질문 & 토론 거리**: 스터디 때 같이 얘기하고 싶은 부분
  - **느낀 점 / 회고**: 개인적인 인사이트
- 각 파일 frontmatter의 `status`는 `미작성 → 작성중 → 완료`로 갱신합니다.
