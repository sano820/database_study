## 핵심 요약
기본키 - pk => 모든 행을 유일하게 식별하는 대표 키.
후보키 - 기본 키가 될 수 있는 후보.
    - 유일성 = 행 구분
    - 최소성
    => 대체 키
외래 키 - 테이블 간의 관계를 연결

*최소성* 
-여러 컬럼을 묶어서 하나의 키 = 복합키
    - 굳이 복합키를 사용하지 않는 특징.
    - 최소한의 컬럼을 사용

자연키 
    - 직관성
    - 중복 방지
    - ex) 이메일, 등 ==> 변경 가능성이 존재.

대리키
    - UUID = Universally Unique Identifier

유니크 제약 조건
***대리키 - pk, 자연키 - 유니크***

- 자연키를 복합키로 유니크 제약 조건으로 설정.
