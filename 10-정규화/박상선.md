## 핵심 요약

제1정규형 :
- 모든 컬럼의 값은 원자값(atomic)으로만 이루어져야 함.
예: 한 컬럼에 여러 개의 전화번호나 쉼표(,)로 구분된 태그를 넣는 형태를 분리.

제2정규형 :
- 제1정규형을 만족하고, 기본키(PK)의 진부분집합이 키가 아닌 일반 컬럼을 결정하는 부분 함수 종속을 제거하는 단계.
- 핵심: 복합 기본키(두 개 이상의 컬럼으로 이뤄진 PK)를 사용할 때, 복합키의 일부에만 종속되는 컬럼을 별도의 테이블로 분리함.
==> 대리키를 이용하는 경우 제2정규형이 발생할 수 있음

제3정규형 :
- 제2정규형을 만족하고, 이행적 함수 종속을 제거하는 단계.
- 핵심: A -> B, B -> C 형태가 성립할 때, 일반 컬럼이 다른 일반 컬럼을 결정하는 구조를 없애고 테이블을 쪼갬. (식별자가 아닌 일반 컬럼 간의 종속 제거)

BCNF 정규형 :
- 테이블의 모든 결정자가 후보키.
